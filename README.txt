AI MR BOSS — GitHub Pages

Deploy:
1. Buat repository bernama aimrboss.github.io pada akun GitHub aimrboss.
2. Upload index.html ke root repository (bukan ke dalam folder lain).
3. Buka Settings > Pages.
4. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
5. Tunggu proses deployment, kemudian buka https://aimrboss.github.io/

Canonical dan metadata sudah diarahkan ke https://aimrboss.github.io/.
Edit teks, warna, atau tautan langsung di index.html.
